# Forte Releases

Public, binary-only distribution for signed Forte desktop releases.

This repository contains macOS installers and update metadata published by the private Forte source repository. It does not contain application source code, signing credentials, or GitHub access tokens.

Download the latest signed release from the [Releases](https://github.com/forte-labs/forte-releases/releases) page. Forte itself checks this public feed and always requires an explicit user action before downloading or restarting to install an update.
